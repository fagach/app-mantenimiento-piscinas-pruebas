# App Mantenimiento Piscinas — entorno de pruebas

Repositorio independiente para validar cambios y nuevas funciones de la aplicación de mantenimiento de piscinas.

- No contiene datos reales de clientes ni fotografías reales.
- No modifica el repositorio ni la aplicación principal.
- Los cambios aquí se revisan y prueban antes de considerar cualquier incorporación al proyecto principal.
- No publicar credenciales, claves privadas, tokens ni información de usuarios.

Este repositorio contiene únicamente los archivos estáticos necesarios para el piloto web.
